# Icon assets

The 16×16 UI glyphs (`*_16x.png`) are from the **Microsoft Visual Studio Image Library**. The brand
logos (`DiscordLogo`, `GitHubLogo`, `DonateLogo`, `RuneberryLogo`, `vsg_logo_16`) belong to their
respective owners.

These are the **original** assets that shipped with the WinForms 2.x app (the `main` branch). They are
restored here verbatim for the v3 (Avalonia) UI so the look is pixel-identical to the original.

## Project-original glyphs

`PlayStation_16x.png` and `Nintendo_16x.png` are **not** from the VS Image Library — they are simple
platform indicators drawn for v3 when crossplay list-management added PlayStation/Switch support (the
VS Library has no such glyphs). They depict generic platform shapes (the PlayStation face-button symbols;
a Switch-style two-Joy-Con silhouette) rather than any wordmark, and are original to this project, so the
gray area below does not apply to them.

**Licensing note:** the VS Image Library license technically restricts redistribution to use within
Microsoft-tooling contexts. This is a known gray area that the project has shipped under since the
WinForms releases. The decision to keep using them for v3 was made deliberately (parity over a
from-scratch icon set); documented here so the choice is discoverable rather than silent.
